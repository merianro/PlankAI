# PlankAI

AI-powered system for generating furniture cutting lists (despieces) and optimizing wood panel usage.

## Features

- **Blueprint Analysis** — Upload furniture plans in multiple formats (images, CAD files, PDFs)
- **Piece Decomposition** — AI automatically identifies and extracts individual pieces
- **Material Calculation** — Calculates exact number of panels needed
- **Cutting Optimization** — Nesting algorithm minimizes waste and optimizes cuts

## Target Audience

Professional woodworkers, furniture makers, and carpentry workshops.

## Tech Stack

- **AI/ML** — Computer vision for blueprint analysis
- **Optimization** — Nesting algorithms for cutting plans
- **Input Support** — Images, CAD (DWG/DXF), PDF
